# Role-2-Protocol-Addressing
In this project i understand that every protocol involved in opening to a secure website, laid out by which TCP/IP layer it belongs to
DNS, which resolves the domain name and HTTP wrapped in TLS
TCP is what carries that request reliably using source and destination ports
Port 53 — DNS: resolves domain names to IP addresses; runs over UDP (or TCP for larger responses)
Port 443 — HTTPS: encrypted web traffic over TCP, secured with TLS

This shows that all protocol are following proper channels in order good communications
